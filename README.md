# NUCLEO-WB55 + FreeRTOS + OLED + USB + Bluetooth

Учебный проект для платы **NUCLEO-WB55RG** (STM32WB55, Cortex-M4 + радио-ядро Cortex-M0+).
Написан на регистрах, без HAL: CMSIS, FreeRTOS и для Bluetooth транспортный слой ST (STM32_WPAN).

## Что умеет

- **OLED 0.96" 128×64** (SSD1306, I2C): в заголовке надпись, значки USB и Bluetooth и температура чипа; ниже 6 строк текста с прокруткой; внизу бегающая точка («софт жив»).
- **USB COM-порт** (разъём USB_USER): команды с компьютера.
- **Bluetooth LE**: устройство `WB55-OLED`.
  - Nordic UART Service (те же команды, что по USB). На Android подойдёт приложение *Serial Bluetooth Terminal*.
  - Environmental Sensing → Temperature (обновляется раз в секунду).
- **Датчик температуры** внутри чипа (АЦП с заводской калибровкой).
- **Осциллограф** на OLED: вход A2, тестовый ШИМ на D3, управление кнопками SW1–SW3.
- **Синий светодиод**: тусклое мигание через программный ШИМ на TIM17.

### Команды (USB и Bluetooth)

| Команда | Действие |
|---|---|
| любой текст | показать на дисплее |
| `clear` | очистить текст на дисплее |
| `temp` | температура чипа |
| `led N` | яркость синего светодиода, 0..100 % |
| `ble` | состояние Bluetooth и версия стека |
| `help` | список команд |

Кнопка **SW1** отправляет сообщение о нажатии в оба канала.

## Осциллограф

АЦП снимает сигнал с **A2 (PA1)**: TIM2 задаёт моменты измерений, DMA складывает 512 точек в память, программа находит триггер (фронт через середину) и рисует 128 точек. Частоту и скважность программа меряет сама по записанному сигналу.

Тестовый сигнал — ШИМ от TIM1 на **D3 (PA10)**. Соедини проводком **D3 → A2**.

⚠️ На вход подавать только **0…3.3 В**. Больше или с минусом — только через делитель и смещение.

| Кнопка | Действие |
|---|---|
| SW1 | скважность ШИМ +10% (10…90%) |
| SW2 | развёртка: 20 мкс … 10 мс на клетку |
| SW3 коротко | RUN / HOLD |
| SW3 держать 1 с | экран: текст ↔ осциллограф |

Команды: `scope` (переключить экран), `pwm N` (скважность, %), `pwmf N` (частота ШИМ, Гц).

## Подключение дисплея

| OLED | Nucleo |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SCL | D15 (PB8) |
| SDA | D14 (PB9) |

## Сборка и прошивка

Тулчейн берётся из установленного STM32CubeIDE (пути заданы в `Makefile`):

```
make          # сборка
make flash    # прошивка через ST-Link
```

Во втором ядре должен стоять **BLE_Stack_full 1.24.0** (из пакета STM32Cube_FW_WB 1.24.0).

## Структура

```
Core/Src/main.c           задачи FreeRTOS, команды, экран
Core/Src/i2c.c            I2C1 на регистрах (с восстановлением зависшей шины)
Core/Src/ssd1306.c        драйвер дисплея
Core/Src/usb_cdc.c        USB CDC (виртуальный COM-порт) на регистрах
Core/Src/temp.c           датчик температуры через АЦП (+ общий доступ к АЦП)
Core/Src/scope.c          осциллограф: ШИМ, захват TIM2+АЦП+DMA, триггер, отрисовка
Core/Src/wpan/hw_ipcc.c   «почтовый ящик» между ядрами (IPCC)
Core/Src/wpan/ble_app.c   Bluetooth: запуск радио-ядра, сервисы, реклама
Middlewares/FreeRTOS      ядро FreeRTOS 10.6.2
Middlewares/STM32_WPAN    транспорт и команды BLE от ST
```

## Грабли, на которые наступили

Без этих трёх вещей `SHCI_C2_BLE_Init` зависает навсегда и не сообщает никакой ошибки:

1. Должен быть включён **HSI16**: без него радио-ядро не может писать во Flash.
2. При старте нужно сбросить флаг **FLASH OPTVERR**.
3. Тактирование **RNG** (от HSI48) включает наше ядро, а не радио-ядро.
